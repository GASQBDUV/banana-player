# Crash log (2026-11-09)

## Why

Only two runs of `log.txt` are kept (`log.txt`, `log.prev.txt`), so older crashes were lost.

## Design (`src/crashlog.cpp`, `src/crashlog.h`)

- SIGSEGV, SIGBUS, SIGILL, SIGFPE, SIGABRT and uncaught exceptions append a record to `<state>/crash.log`: time,
  version and commit, signal, code and address, thread, what was playing, up to 64 frames. A `crash:` line goes to
  stderr (so to log.txt), then the signal is raised again so the process dies as before.
- Only async-signal-safe calls in the handler. `sigaltstack` is set on the main thread only: a stack overflow in an
  mpv thread isn't recorded.
- Size: the file never passes 64 KB; each start trims it to its newest 32 KB once it is over 48 KB; a record is at most
  16 KB.
- Symbolize with `dist/symbols/banana-player-<version>`, the unstripped copy `build-bundle.sh` keeps. The commands are in
  `DEVELOPMENT.md`, "Crash log".
- Test hook: `BP_CRASH_TEST=segv|abort|throw|overflow` (crashes 1.5 s after the start).
